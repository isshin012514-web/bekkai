# 「別解」のつくり方──正解探しをやめて、自分の答えを出す技術

---

学校では「正解」を当てる訓練をします。
でも社会に出ると、**正解が一つに決まらない問い**ばかりです。

- どんなキャリアを選ぶか
- どう差別化するか
- 何に時間を使うか

こういう問いに、テンプレ的な"正解"で答えると、みんなと同じになって埋もれます。
必要なのは、**あなたにしか出せない別解**です。

## 別解＝3つの掛け合わせ

別解は、次の3つが重なるところに生まれます。

| 要素 | 中身 | 偏るとどうなる |
|---|---|---|
| 自分らしい | 経験・価値観・夢中になれること | → 独りよがり |
| 優れている | 大きい・多い・安い・速い等の強み | → コモディティ（埋もれる） |
| 他と違う | 誰もやっていない角度 | → 長続きしない |

**1つに偏ると失敗します。** 3つの重なりを探すのがコツです。

## 別解のつくり方 4ステップ

1. **テーマを決める**（例：自分の学びを伝わる形で発信する）
2. **3つを別々に書き出す**
   - 自分らしいやり方は？
   - 優れたやり方は？
   - 人と違うやり方は？
3. **重なりを言語化する**
   3つを踏まえて「自分ならこうする」を1文に。
4. **マイナス面に手を打つ**
   「他と違う」には必ず弱点が付く。それを補う一手まで決める。

## 出すだけでは足りない

別解は**実現しないと独りよがり**で終わります。
実現のコツは、

- 要素の**組み合わせ**を変える
- **量**をこなして質に変える
- **チーム**で1000点を取る

そして、**根拠のない自信**でメンバーを巻き込む。
